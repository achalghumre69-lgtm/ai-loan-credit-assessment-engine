# AI Credit Assess

A responsive, single-page loan and credit assessment demo.

## Run locally

Open `index.html` in a modern browser.

## Demo limitations

The score, risk estimate, eligibility, interest rate, history, and admin metrics are illustrative sample outputs. The form, document picker, login/register dialog, and report download run in the browser only. No backend, OCR, identity verification, lender decision, or data storage is connected.
